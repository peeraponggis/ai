ทดสอบ CORS — หน้าเว็บเรียก LLM ฟรีได้โดยตรงไหม

คำถามที่ต้องตอบ: ถ้าทำ AI chat เป็น เว็บล้วน เบราว์เซอร์จะยอมให้เรียก API เหล่านี้หรือไม่ — ถ้าไม่ยอม ต้องห่อเป็น APK แล้วเรียกจากฝั่ง Java เหมือนที่เคยทำ
ปลายทางวิธีผล เวลารายละเอียด
อ่านผลอย่างไร
• ผ่าน = เบราว์เซอร์ยอมให้เรียก → ทำเป็นเว็บล้วนได้
• CORS บล็อก = เซิร์ฟเวอร์ไม่ส่ง header Access-Control-Allow-Origin → เบราว์เซอร์ปฏิเสธเอง โค้ดจะเห็นเป็น TypeError: Failed to fetch โดยไม่มีสถานะ HTTP
• HTTP ผิดพลาด = เรียกถึงเซิร์ฟเวอร์แล้ว (CORS ผ่าน) แต่ตัว API ตอบ error เช่น 401/429

ข้อควรรู้: เปิดไฟล์นี้แบบ file:// เบราว์เซอร์จะส่ง Origin: null ซึ่งหลายเซิร์ฟเวอร์ปฏิเสธ — ถ้าผลออกมาว่าถูกบล็อก ควรลองอีกครั้งจากเว็บที่โฮสต์จริง (https) ก่อนสรุปว่าใช้ไม่ได้
