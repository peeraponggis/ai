> วิธีวัด: ยิงจริงจาก GitHub Actions runner (sandbox ของ dev เข้าไม่ถึงโฮสต์เหล่านี้)
> สคริปต์: [`../03-experiments/probe_all_models.py`](../03-experiments/probe_all_models.py)
> ทุกบรรทัดในเอกสารนี้มาจาก HTTP response จริง ไม่ใช่จากเอกสารของผู้ให้บริการ

## สรุปผู้ให้บริการ

| ผู้ให้บริการ | สถานะ | หลักฐาน |
|---|---|---|
| **LLM7 anonymous** (`api.llm7.io/v1`) | ✅ **ใช้ได้ — 7 โมเดล** | HTTP 200 พร้อมคำตอบที่ถูกต้อง |
| LLM7 `pro` | ❌ ต้องจ่ายเงิน | HTTP 402 `pro_access_required` |
| LLM7 โมเดลแบรนด์ดัง | ❌ ต้องมี key | HTTP 401 `invalid_api_key` |
| **Pollinations legacy** (`text.pollinations.ai`) | ❌ **กำลังถูกปิด** | HTTP 402 + `deprecation_notice` ให้ย้ายไป `enter.pollinations.ai` |
| Pollinations `gen.pollinations.ai` | ❌ | HTTP 404 `Model not found` — legacy API |

### บทเรียนที่ 1: ลิสต์โมเดลคือ "เมนู" ไม่ใช่ "สิทธิ์"

`/v1/models` คืนมา **45 ตัว** รวม `claude-opus-5`, `gpt-5.6`, `grok-4.6`, `kimi-k2.6`
แต่พอยิงจริง **ทุกตัวที่เป็นแบรนด์ดังคืน 401** — ต้องทดสอบทีละตัว ห้ามเชื่อลิสต์

### บทเรียนที่ 2: Cloudflare 1010 ไม่ใช่ rate limit

Pollinations ตอบ `403 error code 1010` = ปฏิเสธจากลายเซ็นของ client
(`Python-urllib/3.x`) แก้ได้ด้วยการส่ง `User-Agent` แบบเบราว์เซอร์ — แต่พอทะลุเข้าไป
ก็เจอ 402/404 อยู่ดี เพราะบริการกำลังปิด

| 7 | `mistral-Nemo-Instruct-2407` | Mistral | ⚠️ **`ANSWER: 2000` — ผิด** (ที่ถูกคือ 20000) |

**เงื่อนไขความหลากหลายผ่านแล้ว**: 7 โมเดลนี้มาจาก **5 ค่ายที่ต่างกัน** (DeepSeek, Mistral,
Google, OpenAI, Meta, MiniMax) ซึ่งเป็นสิ่งที่เอกสาร 01 ระบุว่าจำเป็นเพื่อกด φ ให้ต่ำ
— ยังต้องพิสูจน์ด้วยการวัดจริงว่าเป็นโมเดลคนละตัวจริง ไม่ใช่ route ไป backend เดียวกัน

**สัญญาณคุณภาพที่เห็นตั้งแต่ probe**: `mistral-Nemo` ตอบผิด 10 เท่าในโจทย์หารง่าย ๆ
→ ชุดทดสอบน่าจะแยกโมเดลดี/ไม่ดีได้จริง

## ข้อจำกัดที่ต้องบันทึก

1. **แหล่งเดียว** — ทั้ง 7 โมเดลมาจาก LLM7 เจ้าเดียว ถ้าเจ้านี้ล่มหรือเปลี่ยนนโยบาย
   งานทั้งหมดหยุด และถ้าเบื้องหลัง route ไปที่เดียวกัน φ จะสูงจนการโหวตไร้ประโยชน์
2. **ไม่มีสัญญา** — เป็นบริการฟรีแบบ anonymous ไม่มี SLA ไม่มีการรับประกันว่า
   model id เดิมจะยังอยู่พรุ่งนี้ (`deepseek-r1` และ `gpt-4o-mini` ที่เคยมีในเอกสารอื่น
   ตายไปแล้วทั้งคู่) → **ต้อง re-probe ก่อนการวัดทุกครั้ง**
3. **ความเป็นส่วนตัว** — ทุกคำถามถูกส่งออกไปยังเซิร์ฟเวอร์บุคคลที่สาม
   ห้ามใส่ข้อมูลลูกค้าหรือความลับทางธุรกิจ
4. **rate limit** — 429 บอก `retry_after: 1` วินาที ตั้งระยะห่าง 1.5 วิ/request
   → 100 ข้อ × 7 โมเดล = 700 requests ≈ **18 นาที**

## ขั้นถัดไป

ตั้งค่า `run_providers.py` ด้วย 7 โมเดลนี้แล้ว → ยิงชุดทดสอบ 100 ข้อ เพื่อวัด **p และ φ ตัวจริง**
