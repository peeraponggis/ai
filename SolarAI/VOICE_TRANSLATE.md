# แปลเสียง (Voice Translate)

แอป Android ที่ **ฟังเสียงจากไมค์ → แปลเป็นภาษาไทย → พูดออกลำโพง** โดยพยายาม
เลือกเพศของเสียงพูดไทยให้ตรงกับเพศของผู้พูดต้นทางโดยอัตโนมัติ

เป็นโมดูล `:voicetranslate` ในโปรเจกต์ Gradle เดียวกับ Solar AI แต่ build ออกมาเป็น
APK คนละตัว (`com.solarai.voicetranslate`) ติดตั้งพร้อมกันได้ทั้งสองแอป

## การทำงาน

```
ไมค์ → SpeechRecognizer (Android)  →  ข้อความต้นฉบับ
                │
                └─(ถ้าอ่านคลื่นเสียงได้)→ วัด pitch → เดาเพศจากเสียง
                                                            │
ข้อความ → Claude (แปล + เดาเพศจากภาษา ตอบเป็น JSON) ─────────┤
                                                            ▼
                                                  ตัดสินเพศที่จะใช้
                                                            │
                                     TextToSpeech ภาษาไทย → ลำโพง
```

ถอดเสียงและอ่านออกเสียงใช้ของที่มีในเครื่องทั้งหมด **ไม่ต้องมี API key เพิ่ม**
ส่วนที่ต้องต่อเน็ตคือการเรียก Claude API เพื่อแปล (และการถอดเสียงบางภาษาที่
เครื่องยังไม่มีโมเดลออฟไลน์)

## วิธีใช้

1. ติดตั้ง APK แล้วเปิดแอป → ใส่ Anthropic API Key (`sk-ant-api03-...`)
   เก็บใน SharedPreferences ของแอป ไม่ต้องใส่ซ้ำ
2. เลือกภาษาที่จะฟัง (Android 13+ เลือก "อัตโนมัติ" ให้ระบบเดาเองได้)
3. แตะปุ่มไมค์ → พูด → แตะอีกครั้งเพื่อหยุด
4. แอปจะแสดงข้อความต้นฉบับ คำแปลไทย และป้ายบอกเพศของเสียงพร้อม**ที่มาของการเดา**
   แล้วอ่านออกเสียงให้อัตโนมัติ
5. ถ้าเพศผิด **แตะที่ป้ายเพศ** เพื่อสลับแล้วให้พูดซ้ำได้ทันที

## การเลือกเพศของเสียง — ทำงานอย่างไรและแม่นแค่ไหน

แอปไล่ใช้สัญญาณตามลำดับนี้ ป้ายบนหน้าจอจะบอกเสมอว่ารอบนั้นใช้สัญญาณไหน

| ลำดับ | สัญญาณ | ป้ายที่แสดง | ใช้ได้เมื่อไหร่ |
|---|---|---|---|
| 1 | ผู้ใช้ตั้งเอง (ชายเสมอ/หญิงเสมอ หรือแตะสลับ) | ตั้งเอง | เสมอ |
| 2 | ระดับเสียง (F0) ของผู้พูดจากคลื่นเสียงจริง | จากเสียง | Android 13+ ที่มีตัวถอดเสียงในเครื่อง |
| 3 | ร่องรอยทางภาษาในประโยค — Claude เป็นคนเดาให้ | จากภาษา | ทุกเครื่อง (เมื่อประโยคมีคำบ่งเพศ) |
| 4 | เพศที่ตัดสินได้ล่าสุดในเซสชัน | ค่าล่าสุด | เมื่อ 2 และ 3 เดาไม่ออก |
| 5 | ค่าเริ่มต้น (เสียงหญิง) | ค่าเริ่มต้น | ประโยคแรกที่เดาไม่ออก |

**ข้อจำกัดที่ควรรู้ก่อนใช้งานจริง:**

- **ชั้นที่ 2 ใช้ไม่ได้ทุกเครื่อง** ปกติ `SpeechRecognizer` ของ Android ยึดไมค์ไว้คนเดียว
  แอปจึงไม่เห็นคลื่นเสียง แอปนี้เลี่ยงด้วยการอัดเสียงเองแล้วป้อนให้ตัวถอดเสียงในเครื่อง
  (`EXTRA_AUDIO_SOURCE`) ซึ่งทำได้เฉพาะ Android 13+ ที่ดาวน์โหลดโมเดลภาษานั้นไว้แล้ว
  ถ้าทำไม่ได้ แอปจะถอยไปใช้ตัวถอดเสียงปกติให้เองโดยไม่แจ้งเตือน
  ดูสถานะจริงของเครื่องได้ที่ท้ายหน้าตั้งค่า
- **การเดาจากระดับเสียงแม่นราว 85%** กับเสียงผู้ใหญ่ในที่เงียบ และพลาดได้กับเสียงเด็ก
  เสียงกระซิบ ผู้ชายเสียงสูง ผู้หญิงเสียงทุ้ม และห้องที่มีเสียงรบกวน
  ช่วง 155–180 Hz ถือว่าคาบเกี่ยว แอปจะตอบ "ไม่รู้" แทนการเดามั่ว
- **การเดาจากภาษาจะได้ผลเมื่อประโยคมีคำบ่งเพศ** เช่น ครับ/ค่ะ, ผม/ดิฉัน,
  僕/あたし, หรือการผันคำตามเพศในภาษาฝรั่งเศส สเปน รัสเซีย อาหรับ
  ประโยคอย่าง "Where is the station?" ไม่มีร่องรอยเลย จะได้ "ไม่รู้"
  prompt สั่งห้ามเดาจากหัวข้อที่พูดหรือจากภาพเหมารวมเรื่องอาชีพ/ความสนใจโดยเด็ดขาด
- ทั้งหมดนี้เป็นการอนุมานจาก**ลักษณะของเสียงและถ้อยคำ** ไม่ใช่การระบุตัวตนของบุคคล
  จึงต้องให้ผู้ใช้แก้เองได้เสมอ — แตะป้ายเพศเพื่อสลับได้ทุกเมื่อ

## เสียงพูดภาษาไทย

Android **ไม่มีฟิลด์บอกเพศของเสียง** ใน `Voice` API และชื่อเสียงของแต่ละ engine
ก็ไม่มีรูปแบบมาตรฐาน จึงไม่มีทางรู้ได้จากโค้ดว่าเสียงไหนเป็นชายหรือหญิง แอปจึงทำสองแบบ:

- **ยังไม่ได้จับคู่เสียง (ค่าเริ่มต้น)** — ใช้เสียงไทยตัวเริ่มต้นของเครื่อง
  แล้วดัดให้ทุ้ม (pitch 0.85) หรือแหลม (1.12) หยาบกว่าแต่ได้ยินความต่างทันทีทุกเครื่อง
- **จับคู่เสียงเองในหน้าตั้งค่า** — กด ▶ ฟังเสียงไทยแต่ละตัวที่ติดตั้งอยู่
  แล้วกดเลือกว่าตัวไหนเป็น "ชาย" ตัวไหนเป็น "หญิง" ให้ผลดีกว่ามาก แนะนำให้ตั้งครั้งเดียวตอนแรก

ถ้าเครื่องยังไม่มีข้อมูลเสียงภาษาไทย แอปจะขึ้นแถบแจ้งเตือนพร้อมปุ่มพาไปหน้าติดตั้ง

## Build

เหมือน Solar AI ทุกอย่าง (ดู [BUILD_INSTRUCTIONS.md](BUILD_INSTRUCTIONS.md)) —
`./gradlew assembleDebug` ที่โฟลเดอร์ `SolarAI` สร้าง APK ให้ทั้งสองโมดูลในครั้งเดียว

| | ที่อยู่ |
|---|---|
| APK | `voicetranslate/build/outputs/apk/debug/voicetranslate-debug.apk` |
| artifact ใน GitHub Actions | `voice-translate-debug-apk` |
| unit test | `./gradlew :voicetranslate:testDebugUnitTest` |

`vendor/` (Tailwind, Font Awesome, ฟอนต์) อยู่ที่ `SolarAI/shared-assets/` ใช้ร่วมกับ
แอป Solar AI — ถ้าเพิ่ม Tailwind class ใหม่ใน `index.html` ของโมดูลไหนก็ตาม
ต้องรัน `npm run build` ใน `tools/css` แล้ว commit ไฟล์ CSS ที่ generate ใหม่ด้วย

## โมเดลที่ใช้แปล

เลือกได้ในหน้าตั้งค่า ค่าเริ่มต้นคือ `claude-opus-5` (แปลดีที่สุด) เปลี่ยนเป็น
`claude-sonnet-5` หรือ `claude-haiku-4-5` ได้เมื่ออยากให้ตอบเร็วขึ้น
คำขอใช้ structured outputs (`output_config.format`) ให้โมเดลตอบเป็น JSON
ที่มีทั้งคำแปลและผลเดาเพศในครั้งเดียว — ไม่มีค่าใช้จ่ายหรือเวลารอเพิ่มจากการเดาเพศ

## ความปลอดภัย

API Key เก็บเป็น plain text ใน SharedPreferences ของแอป (อ่านได้เฉพาะแอปนี้
ในเครื่องที่ไม่ root) เหมาะกับการใช้งานส่วนตัว/ภายในองค์กร ไม่ควรแจกจ่าย APK ที่ฝัง key
ให้บุคคลภายนอก เสียงที่อัดไม่ถูกเก็บลงไฟล์ — ใช้ในหน่วยความจำระหว่างถอดเสียงเท่านั้น
ข้อความที่ถอดได้ถูกส่งไปยัง Anthropic API เพื่อแปล
