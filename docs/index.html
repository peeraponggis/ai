โมเดลที่เปิดใช้

ผู้ให้บริการจำกัดอัตราเรียก ต่อบัญชี ไม่ใช่ต่อโมเดล จึงต้องยิงทีละตัวห่างกัน 1.5 วินาที — เลือกโมเดลมาก = ตอบช้าลงตามจำนวน

สถาปัตยกรรม 3 ชั้น

L1 — โค้ดคำนวณ
ตัวเลขคำนวณด้วยโค้ดในหน้านี้เสมอ ไม่ให้โมเดลคิดเลข (codestral เคยตอบ 100000÷5 = 40,000)

L2 — โมเดลอ่านและอธิบาย
ใช้หลายโมเดลตอบอิสระ แล้ววัดว่าตรงกันแค่ไหน ตามแนวคิด Self-Consistency / Mixture-of-Agents

L3 — คนตัดสิน
เมื่อโมเดลขัดแย้งกัน ระบบจะบอกตรง ๆ ไม่กลบ ไม่เลือกข้างให้เอง

ความสอดคล้อง ≠ ความถูกต้อง

ตัวเลข "ความสอดคล้อง" คือโมเดลตอบตรงกันแค่ไหน ไม่ใช่ความน่าจะเป็นที่คำตอบถูก ถ้าโมเดลผิดเหมือนกันหมด ค่านี้จะสูงทั้งที่คำตอบผิด
การแปลงค่านี้เป็นความแม่นยำต้อง calibrate ด้วยชุดทดสอบที่รู้เฉลย — งานวัดนั้นยังไม่เสร็จ จึงยังไม่แสดงเป็นเปอร์เซ็นต์ความถูกต้อง
